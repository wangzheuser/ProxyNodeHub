# 客户端与 Web 能力对照

本次依据实际调用链盘点，不以 README 或按钮文案替代可工作能力。Windows 宿主、共享 Core、独立 subs-check 各自保持数据和进程所有权。

本页记录前一轮补齐清单，不代表所有客户端功能等价。后续完整复核确认仍有实质差异，部署决定与剩余方案见 [Web组件与完整能力复核](web-parity-review.md)。

## 补齐方案

| 能力 | 原差异 | 本次实现方式 |
|---|---|---|
| GitHub Token | 桌面可输入，Web 只有环境变量状态 | 在线设置、更换、禁用、恢复环境；服务端加密保存，下一轮发现生效 |
| 检测器连接 | URL/API Key/Web URL 只能重建容器配置 | 同一连接存储；空密钥仅保留同地址已有自定义密钥，换地址必须重填 |
| 仓库过滤与排序 | Web 只有文本与少量固定方向排序 | 补日均提交、库龄、不活跃过滤及排序方向，不改变后台公开清单 |
| 选择与复制 | 缺批量选择及单条/批量复制 | 明确全部、筛选、选中范围；HTTP 下提供文本选择复制 |
| 批量收藏 | 一次只能操作一个 | 服务端一次原子提交，显式添加/移除，失败不部分成功 |
| 单个/批量重检 | 只能重新完整搜索 | 复用后台互斥与发现核心，合并选中结果，不删未选来源、不复活已取消收藏 |
| 按范围导出 | 文本过滤不影响导出 | 服务器按已知仓库名称解析；不接受任意抓取 URL |
| 搜索记忆 | 只有任务日志，没有仓库排除记忆 | 独立显式“探索新来源”使用近期/收藏排除；普通刷新与定时任务不受排除影响 |
| 日志管理 | 固定最新轮展示，无逐轮查看/清理 | 逐轮查看下载、保留期限、清理日志；保留完成时间及结果，调度不抢跑 |
| 处理并发 | Web 固定串行 | 可设1–10，默认仍1；仓库数上限100；使用同一分析流程，不将并发伪装为不同探测深度 |
| 下载镜像 | Web 忽略桌面已有镜像能力 | 固定镜像列表、测速/选择/自动；原始 URL 仍受公开来源限制，Token 不离开 GitHub API，不跟随重定向 |
| 检测控制 | 只有开始，无取消/日志/版本 | 固定 API 请求停止、脱敏日志、版本；收到停止响应不等于本轮已结束 |
| 测速参数 | Web 无表单 | 安全白名单字段编辑，原稿版本比对，保留未知键和敏感字段，不回传完整配置 |
| 检测来源 | 只有当前发现公开清单 | 当前/收藏/手动来源显式追加到检测器原来源，带仓库标签；不覆盖原配置，不公开私密手动URL |
| 检测产物 | 只有来源清单复制 | 下载检测器真实生成的 Clash/Mihomo/Base64，不从无凭据结果伪造订阅 |
| 检测结果筛选/归因 | 缺速度排序与仓库反馈 | 按速度筛选排序、按 subTag 统计已保留节点数量/速度；不伪造通过率 |

## 凭据合同

`/data/connections.protected` 由 ASP.NET Data Protection 加密；`/data/keys` 是同一应用原有密钥环。备份二者并保护整个数据卷，丢失密钥环后不能解密；这不防御已经拥有完整卷读取权限的管理员。磁盘损坏或解密失败显式启动失败，不静默退回环境令牌。

每组连接有 `environment`、`custom`、`disabled` 三种来源。无自定义记录时使用环境变量；自定义覆盖环境；禁用不会悄悄启用环境。恢复环境会移除当前自定义值。历史 `.bak` 仍为加密备份，清除配置不是对历史备份的安全擦除。页面不读取已保存明文，密钥与私密订阅不写 localStorage；浏览器只保存经过白名单校验的筛选数值、排序及显示列。内网 HTTP 本身仍不加密，跨不可信网络须 HTTPS。

保存不强制验证网络有效性，不立即触发发现/检测。GitHub 下轮任务读取新值，正在执行的任务保持旧快照；检测请求逐次捕获连接快照。

## 不是应原样复制的功能

1. **Windows 内核安装/路径/自动更新**：桌面拥有本机 exe；Web 连接外部容器，只显示版本和原管理页入口，不安装 exe、不挂 Docker socket、不替外部管理员重启服务。
2. **完整 YAML 高级编辑**：原文含 API Key、云服务凭据、私密订阅 URL。完整编辑留在检测器原管理页；Web 投影白名单参数并保留未编辑原文。监听端口等配置仍可能需要管理员重启。上游保存 API 没有 CAS，不能保证与其他管理台并行编辑的原子性。
3. **自定义特征码**：`src/CustomFeatureLibrary.cs` 仅由 `FeatureLibraryDialog.cs` 管理，`SubscriptionFinder` 没有调用；原版也是未接线功能。本次不复制无效导入按钮。已学习路径和六层探测一直由共享 Core 实际执行。
4. **最近 N 轮节点回灌**：桌面历史使用缺少连接凭据的结果重建 YAML，不能可靠复用。本次提供检测器原生 `keep-days`，明确为按天保留，不冒充按轮。完整节点产物仍由检测器拥有。
5. **真实通过率/连续零通过降权**：上游 `/api/results` 只含最终保留节点，没有每来源输入总数和失败集合。原桌面以结果集作分母会错误接近100%，零通过仓库也会缺席；本次只展示有证据的保留节点统计。正确实现需上游每来源输入/通过数及完整/取消标记，不能用猜测替代。
6. **Clash/Sing-box合并转换**：桌面 ExportDialog 实际也只有 URI/Base64 合并；更多格式由检测器真实产物提供，不在 Web 重新写转换内核。
7. **窗口位置、最大化和原生快捷键**：使用浏览器原生能力，不拦截 F5/Ctrl+D 等浏览器快捷键。
